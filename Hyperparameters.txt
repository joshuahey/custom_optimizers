# ============================================================
# DG / DG-Delta hyperparameters
# ============================================================
#
# Main parameters
# ---------------
# h : float
#     Step size. 
#     Larger h may speed things up, but if it is too large, the fixed-point iteration may become unstable or fail to converge.
#
# gamma : float (default choices 0.5 - 0.9)
#     Damping parameter (classical momentum damping constant)
#     

#
# delta : float   (DG_Delta only)
#     Extra gradient damping in the theta update.
#     If it is too large, it may slow convergence.
#
# fp_iters : int (default choices 1 - 3)
#     Maximum number of fixed-point iterations used to approximate theta_{k+1}.
#     Since DG and DG-Delta are implicit methods, theta_{k+1} is obtained by
#     solving a fixed-point equation.
#
# avf_samples : int (default choices 1 or 2)
#     Number of quadrature samples used to approximate the AVF discrete gradient
#
#         gbar = ∫_0^1 ∇L((1-s) theta_k + s theta_{k+1}) ds.
#
#     Larger values give a more accurate approximation, but cost increases.
#
# fp_tol : float (default choices 1e-1 -  1e-3)
#     Tolerance for early stopping of the fixed-point iteration.
#     If successive fixed-point iterates are close enough, the inner solve stops
#     early. Smaller fp_tol gives a more accurate inner solve, but costs more.
